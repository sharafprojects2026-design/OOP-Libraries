# OOP Libraries

A collection of reusable C++ libraries developed as part of my learning journey in **Problem Solving and Object-Oriented Programming (OOP)**.

## 📚 Libraries

### String Library

A reusable C++ string library containing functions for common string operations, including:

* Counting words and letters
* Converting letters and strings to uppercase or lowercase
* Inverting letter case
* Counting vowels
* Splitting and joining strings
* Trimming strings
* Reversing words
* Replacing words
* Removing punctuation
* And other useful string operations

### Date Library

A reusable C++ date library for handling and manipulating dates, including different date-related operations and utilities.

## 🧠 Concepts Applied

This project allowed me to apply several programming and OOP concepts, including:

* Classes & Objects
* Encapsulation
* Constructors
* Static Members
* Properties
* Functions & Function Overloading
* Vectors
* Pointers
* Dynamic Memory
* Reusable and Modular Code
* Object-Oriented Design

## 🎯 Purpose

The main purpose of this project was to transform the concepts learned throughout my **Problem Solving and OOP courses** into practical, reusable libraries.

The functions used in the libraries were developed progressively throughout the Problem Solving courses and later organized into reusable components using OOP principles.
