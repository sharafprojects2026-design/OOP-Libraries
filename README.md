# OOP Libraries

A collection of reusable C++ libraries developed as part of my journey in **Object-Oriented Programming, Problem Solving, and Software Development**.

## 📌 About The Project

During my **Programming Problem Solving** courses, I solved many programming problems and developed different **functions and procedures** to handle common operations related to strings, dates, periods, and other programming tasks.

Instead of keeping these solutions as separate pieces of code inside different problem-solving projects, I decided to **collect, organize, improve, and reuse them as independent C++ libraries**.

This project represents the transition from simply solving programming problems to building **reusable and maintainable software components**.

> The functions and procedures included in these libraries were previously implemented and tested during my Programming Problem Solving practice. They were later collected, organized, and transformed into reusable libraries.

---

## 📚 Libraries

The repository is organized into separate libraries, where each library contains functions and procedures related to a specific purpose.

### 🗓️ Date Library

The **Date Library** contains reusable functions and procedures for working with dates and date-related operations.

It includes functionality for:

* Date validation
* Date comparison
* Adding and subtracting days
* Calculating differences between dates
* Working with periods
* Date calculations
* Date formatting and manipulation
* Other date-related operations

📁 Location:

```text
Date-Library/
```

---

### 🔤 String Library

The **String Library** contains reusable functions and procedures for common string manipulation and processing operations.

It includes functionality such as:

* Counting characters
* Counting words
* Counting specific characters
* Changing letter case
* Inverting character case
* Splitting strings
* Joining strings
* Trimming strings
* Replacing text
* String validation
* Other string-related operations

📁 Location:

```text
String-Library/
```

## 🧠 Problem Solving → Reusable Libraries

One of the main goals of this project is to demonstrate how **problem-solving practice can evolve into reusable software components**.

The development process was:

```text
Programming Problems
        ↓
Problem Solving
        ↓
Functions & Procedures
        ↓
Testing & Debugging
        ↓
Refactoring
        ↓
Reusable Libraries
```

The functions were not created randomly for this repository. Most of them were originally developed while solving programming problems and practicing algorithmic thinking.

After gaining more experience with **OOP, code organization, and software design**, I collected these solutions and transformed them into structured libraries that can be reused in future projects.
